# LIFT

PWA de hipertrofia + Zona 2 para iPhone. Publicado em GitHub Pages.

**Site:** https://fckpepo.github.io/lift/

O repositório antigo [`treino`](https://github.com/fckpepo/treino) não é alterado.

## iPhone

1. Abra o site no **Safari** (não no Chrome).
2. Compartilhar → **Adicionar à Tela de Início**.
3. Abre em tela cheia, sem barra do Safari.

## Semana do plano

A semana 1 começa na **segunda da semana do primeiro treino marcado**. Depois o número avança sozinho toda segunda. Concluir um treino só registra aderência — não muda o calendário.

## Semana (seg–sex)

| Dia | Sessão |
| --- | --- |
| Seg | Upper A (~45 min) |
| Ter | Lower A — quad, Hack (~45 min) |
| Qua | Zona 2 bike / elíptico (40 min, teto 45) |
| Qui | Upper B (~45 min) |
| Sex | Lower B — posterior + RDL (~45 min) |

Sábado e domingo não são programados. Cada sessão de dia de semana cabe em **45 minutos** com descanso de 2–3 min nos compostos (menos séries, não menos rest).

## Joelho

Sem agachamento livre, Smith, afundo, corrida ou salto. Hack em amplitude sem dor; se inflamar, Leg Press.

## Local

Conclusões ficam no `localStorage` do aparelho. Sem backend e sem dieta nesta versão.
